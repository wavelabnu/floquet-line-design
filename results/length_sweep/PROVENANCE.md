# Provenance — 2.0 GHz length-sweep study

This directory is the verbatim public copy of the TVTL length-sweep study
("optimal N and threshold-vs-length scaling"). It was imported into the tracked
tree from gitignored scratch; the study's own `REPORT.md` is copied unedited
except one word (line 36, "The brief's" → "The study's", 2026-10-12; no number or
table changed). This `PROVENANCE.md` is a separate, added file.

- **Origin path:** `runs/length_sweep/results/` — gitignored scratch (`runs/` is
  in `.gitignore`). This is a COPY out of `runs/`; the scratch was never
  un-ignored.
- **Generation date:** 2026-06-11 (source file mtimes span 2026-06-11
  15:58–19:03 local).
- **Imported:** 2026-07-18.
- **Conditions:** Varactor A, 2.0 GHz signal, 4.0 GHz pump, accurate VIAGND/MLEF
  terminations; `n_cells` swept 6–30 (step 3, 9 points); primary candidate
  `proxy_n3_single_short`, secondary candidate `n3_double_combined`. **No 1.7 GHz
  content** — no 1.7 GHz length sweep exists.

## Import scope (trim)

The source `runs/length_sweep/` directory also held ~933 MB of ADS
harmonic-balance workspace scratch under `outputs/parity_confirm/` (`.ds`
datasets, `spectra.raw`, regenerable OpenAccess workspaces) plus generator
scripts (`step_sweep.py`, `sweep_spec.py`, `make_report.py`, …), run logs, and
simulator configs (`de_sim.cfg`, `hpeesofsim.cfg`). Only the **824 KB study
record** — this directory — was imported; the ADS scratch and generators are
regenerable and are not the public record, so they were not imported.

## Files

- `REPORT.md` — the study report (verbatim apart from the one-word change noted above).
- `sweep_table_primary.csv`, `sweep_table_secondary.csv` — per-N summary tables.
- `sweep_record_primary_N{06,09,12,15,18,21,24,27,30}.json` and the matching
  `sweep_record_secondary_N*.json` — per-N records.
- `matching_drift.json` — edge-impedance drift vs N (the freeze-decision basis).
- `prediction_vs_N.json` — analytical optimism proxy vs N.
- `curves_primary.png`, `curves_secondary.png` — the study's own curve figures.

The public Fig 2d, `fig2d_length_sweep.png` (primary-only), is generated by
`examples/fig2d_length_sweep.py` from `sweep_table_primary.csv`.
